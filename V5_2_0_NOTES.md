# VastuAI Platform v5.2.0 — Simplified AI Portfolio Consultant

- Replaced the repetitive static Portfolio Consultant dashboard with one AI-first workspace.
- Select a buyer and use either the full shortlist or exactly two shortlisted properties.
- Static best-overall / best-Vastu / best-Numerology / ranking / strengths / concerns sections are no longer rendered on the page.
- Comparison tables and reasoning are generated only when the user asks the AI Consultant.
- Two-property comparisons send only the selected PDPs to the model.
- Deterministic saved PDP scores remain immutable and are never recalculated.
- Conversation memory is isolated by the exact hashed portfolio/selection snapshot.
- Navigation label changed to **AI Portfolio Consultant** to distinguish it from the single-property AI Consultant.
