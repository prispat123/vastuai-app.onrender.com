# VastuAI Platform v5.3.0 — Property-Centric Professional UI

## Changes
- Professional landing page is now **Properties**, not a project-management list.
- Saved Professional properties are listed across the underlying Professional data container(s).
- Users can search, sort, select and open a property directly.
- **Add Property** opens a blank assessment using the existing project storage model invisibly.
- Builder / Project Intelligence remains project-based.
- Individual **AI Consultant** restores six suggested question buttons.
- Underlying project IDs are retained for backward compatibility, audit history and all existing services.
